# Third-party references

MoonStatsD library implementation and test cases are newly written. No upstream
client or collector implementation is vendored in the library. Standard Apache-2.0
license text was generated by the MoonBit project template.

| Component | Fixed version | License / role |
|---|---|---|
| moonbitlang/async | 0.20.0 | Apache-2.0; actual library dependency, source/API inspected |
| moonbitlang/core | SDK v0.10.16+b1a0e846e | Apache-2.0; SDK dependency |
| DataDog/documentation | 41384078b8ba37e2cd12e825584ffa8cd66703f7 | BSD-3-Clause; official protocol text read, no document text copied |
| statsd/statsd | v0.9.0 | MIT; protocol reference and external test receiver |
| DataDog/datadog-go | v5.8.3 | MIT; behavior reference and separate Go differential executable |
| prometheus/statsd_exporter | v0.28.0, c0a390a2c43f77863278615b47d46e886bdca726 | Apache-2.0; external interoperability receiver |

License files read from the fixed sources, retained with local downloads under
.local/references or the upstream extracted distributions. The test installer
preserves LICENSE files in downloaded collector directories. Those external
artifacts, SDKs, caches and credentials are excluded from Git and the Moon package.
Go test-only dependencies are recorded by go.mod/go.sum and fetched separately;
no Go implementation is copied into the MoonBit library. The custom StatsD test
backend is an output adapter for official receiver aggregates, not a receiver.

Official references:
- https://github.com/statsd/statsd/tree/v0.9.0
- https://github.com/DataDog/datadog-go/tree/v5.8.3
- https://github.com/prometheus/statsd_exporter/tree/v0.28.0
- https://github.com/moonbitlang/async

No complete Datadog Agent compatibility, collector performance, broad platform
coverage or ecosystem uniqueness is asserted.
